Bảng Công Thức Trọng Tâm Kỹ Thuật Đo Lường Điện (TEE0327)

Chương 1 & 2: Sai số & Đặc tính thiết bị đo

  • Thang đo (Span): Sx = xmax − xmin
  • Độ nhạy tĩnh: K = ΔyΔx ; Độ lệch nhạy theo nhiệt độ: ΔKΔT = |KT2 − KT1||T2 − T1|
  • Độ trôi điểm không theo nhiệt độ: Δy0ΔT (khi x = 0)
  • Ngưỡng nhạy & Độ phân giải: ε = D% · Sx100 ; Khả năng phân ly: R = Sxε
  • Hàm truyền thiết bị đo so sánh: y = KT1 + KT·KN · x
  • Sai số tiêu thụ công suất Ampe kế: γI = RARt + RA · 100% ≈ RARt · 100%

Chương 3: Gia công kết quả đo

  • Sai số tuyệt đối từ cấp chính xác: Δx = Class% × Sx100
  • Sai số tương đối tại giá trị đo x: βx% = Δxx × 100%
  • Kết quả phép đo: xr = x ± Δx
  • Phép đo gián tiếp (R = UI, P = U·I): βy = √βU2 + βI2 ; Δy = y · βy
  • Phép đo thống kê (n lần): x̄ = ∑xin ; s = √∑(xi − x̄)2n − 1 ; sx̄ = s√n

Chương 4 & 6: Mạch xử lý tín hiệu & Đo Dòng - Áp

  • Khuếch đại đảo: uout = −R2R1·uin ; Không đảo: uout = (1 + R2R1)·uin
  • Khuếch đại vi sai đối xứng: Uout = R2R1·(U2 − U1)
  • Mạch cộng đảo: Uout = −R4·(U1R1 + U2R2 + U3R3)
  • Mạch chuyển đổi U → I (Howland): Iout = −R2R1·R3 · uin
  • Mạch Shunt dòng DC: Iout = RSRA + RS·Iin ⇒ I = IA·(1 + RARS) ; Rsh = Rctn − 1
  • Mạch phân áp tần số cao: Cuộn cảm KTL ≈ L2L1 + L2 ; Tụ điện KTL ≈ C1C1 + C2
  • Máy biến dòng (BI) & Biến áp (BU): I = KI·IA ; U = KU·UV ; ΔI = √(KI·ΔIA)2 + (IA·ΔKI)2

Chương 5, 7, 8 & 9: Cảm biến, Công suất & Cầu đo

  • Biến trở thẳng / tròn: Rx = R·xl ; Rtđ = (R − Rx) + (Rx // Rv)
  • Tenzo & Cầu đo: ΔRR0 = K·Δll0 ; Cầu bán phần: Ura = −EN·ΔR2R0 ; Cầu toàn phần: Ura = −Kkđ·EN·ΔRR0
  • Cân băng định lượng: Q = W · RL (kg/phút) ; LVDT: Ura = S · x
  • Công suất & Điện năng: P1p = U·I·cosφ ; P3p = √3·UdIdcosφ = W1 + W2 ; tanφ = √3·(W1 − W2)W1 + W2
  • Công tơ qua BI, BU: Ethực = KI · KU · Eđọc ; Số vòng quay N = A · E (vòng)
  • Cầu Wheatstone & Kelvin: Rx = R1·R3R2 (hoặc R2·R3R1 tùy nhánh)
  • Cầu AC cuộn cảm: Rx = R2R3R1, Lx = R2L3R1 ; Tụ điện: Rx = R2R3R1, Cx = R1C3R2
  • Cầu Maxwell-Wien & Schering: Lx = R2R3C1 ; D = ωR1C1
